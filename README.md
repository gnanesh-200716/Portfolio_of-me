### ◈ 02 — Java PDF-RAG

**Turning documents into searchable knowledge.**

A PDF processing and retrieval-augmented generation project built around document extraction, chunking, embeddings, and a Java backend.

<img src="https://img.shields.io/badge/RAG-DOCUMENT_AI-F5EF69?style=flat-square&labelColor=10100E" alt="Document AI"/> <img src="https://img.shields.io/badge/EMBEDDINGS-3072_DIMENSIONS-FFFFFF?style=flat-square&labelColor=10100E" alt="Embedding dimensions"/>

- PDF text extraction and chunk processing.
- Gemini embedding integration through Spring AI.
- Successfully processed 43 chunks and stored 43 embeddings in the tested workflow.
- REST API testing with Postman.

**Stack:** Java 17 · Spring Boot · Spring AI · Gemini API · React · REST APIs · Postman
